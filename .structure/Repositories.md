# Repositories (Data Access Layer)
Standard Spring Data JPA interfaces for fetching Entities.
* **UserRepository:** `findByEmail`
* **OrderRepository:** `findByUserId`
* **PaymentRepository:** `findByRazorpayOrderId`
* **CouponRepository:** `findByCode`
* **AddonRepository:** `findByIdIn`
* **MenuRepository**, **OrderItemRepository**: Crud defaults.
